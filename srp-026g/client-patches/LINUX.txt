SURVARIUM 0.26g - LINUX

For the Wine scripts, install Bash, curl, tar, and Winetricks (with
cabextract). A Vulkan-capable graphics driver is required for DXVK.
The script uses the system's Wine when it is 11.0+ (tested: 11.8 Staging
WoW64; wine and wineserver from the same installation). Without one it
downloads the Wine of GE-Proton11-12 once into game/binaries/x86/wine-runtime
(570 MB, 1.6 GB unpacked) and runs that, without Steam. Either runs in
modern WoW64 mode. For running the game in your own Proton, see GE-PROTON.

If the script asks for ntsync, run sudo modprobe ntsync, then try again.
To load it automatically at boot:

    echo ntsync | sudo tee /etc/modules-load.d/ntsync.conf

START

Unpack the Skhid archive into an empty folder with about 10 GB free, then run:

    bash Skhid.sh

It updates the Skhid files and the game's patches (the launcher's update,
without its window; the lines of updater_skhid.log show meanwhile), then
starts the game. The first run also downloads the game.
For an existing game, apply the complete archive over its folder.
bash Skhid.sh launcher starts the Skhid launcher instead; press PLAY when
it is ready.

First launch creates a Wine prefix and installs DXVK and the font Calibri (a
27 MB download, which the game's text needs) silently; the launcher's first
start installs Wine Gecko. Later launches reuse them.
Settings: ~/.config/skhid/user.cfg (or $XDG_CONFIG_HOME/skhid/user.cfg).
Select an English keyboard layout before starting to avoid text-input issues.
For VPN setup, see VPN.txt; split tunnelling must cover Wine.

GE-PROTON

GE-Proton11-7 with PROTON_USE_WOW64=1 was tested successfully through
mounting all game resource archives, using a fresh prefix.

Set this environment variable in the launcher that runs Proton (for example,
UMU), before it starts Proton:

    PROTON_USE_WOW64=1

This is a Proton setting, not a game command-line argument. With GE-Proton11-7's
default mode, the same game and resource files reproduced a "Cannot mount
resources.db.patch_..." memory error. Enabling modern WoW64 fixed resource
mounting without lowering the game's memory budgets or replacing patch files.
Simply creating a win64 prefix is not the same as enabling this mode.

IF IT FAILS

The script refuses Wine setups that cannot run modern WoW64. If switching
from older Wine or seeing a white launcher panel, close both, then rename
game/binaries/x86/wineprefix to an unused backup name and launch again.
Settings stored outside the prefix survive its recreation.

For a memory error, check Wine and the prefix first; do not lower the memory
budgets in the script. Report skhid-wine.log and, for update failures,
updater_skhid.log from game/binaries/x86.

For a crash a developer asked to investigate, start with full-memory dumps:

    SKHID_CRASH_DUMP=full bash Skhid.sh launcher

At the end it lists the crash files (a .dmp of 1-3 GB and its .txt report).
